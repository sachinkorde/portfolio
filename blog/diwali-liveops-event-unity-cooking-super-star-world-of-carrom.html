Shipping a Diwali LiveOps Event in Unity: Cooking Super Star & World Of Carrom

How I built a limited-time Diwali festival event, new levels and animated UI popups for AppOn's Cooking Super Star and World Of Carrom mobile games in Unity.

By Sachin Korde, Unity Developer, Pune 2 min read 15 Nov 2026
UnityC#LiveOpsUI AnimationLevel Design

Live mobile games stay alive through events. A good seasonal event gives existing players a reason to come back and gives the game a fresh look. At AppOn, I built a Diwali festival event for two live games: Cooking Super Star – Tasty City and World Of Carrom: 3D Board Game.

What I built

  • A limited-time Diwali event for both games: festival-themed content that appears only for the event period.
  • New levels for Cooking Super Star, extending the game's content.
  • Animated popups: I created the UI animations for popups so rewards and announcements feel exciting instead of flat.
  • Gameplay improvements: I worked side by side with the game designer to refine and improve the game.
  • Performance: I optimized the games for smooth play across devices.

Working with a game designer

Events are a team effort. The game designer defines what the event should feel like and how it should reward players, and the developer makes it real and makes it work. Sitting together, trying things in the game and adjusting quickly is much faster than going back and forth over documents.

Why popup animation matters

Popups are where players get rewards, see offers and learn about events, so they're seen constantly. A popup that animates in with a bit of bounce and timing feels like a celebration, while one that just appears feels like an interruption. Small UI animation work has a big effect on how polished a game feels.

Tech stack

Unity, C#, Unity UI animation, level design, mobile performance optimization.
