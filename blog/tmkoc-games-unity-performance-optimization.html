Optimizing TMKOC Mobile Games in Unity: Run Jetha Run, Match & Merge and Hungry Goli

How I removed lag, smoothed animations and updated 3D models in official TMKOC mobile games built with Unity: Run Jetha Run, Match & Merge: TMKOC Puzzle and Hungry Goli.

By Sachin Korde, Unity Developer, Pune 2 min read 15 Nov 2026
Unity 3DC#OptimizationAnimationMobile

Players forgive a lot, but they don't forgive a game that stutters. While working on official games for TMKOC (Taarak Mehta Ka Ooltah Chashmah), India's No. 1 TV serial, a big part of my job was making existing games run and feel better on real phones.

Run Jetha Run: an endless runner that had to feel smooth

Run Jetha Run is a 3D endless runner starring Jethalal. In a runner, smoothness is the gameplay: if the frame rate drops at the wrong moment, the player crashes into an obstacle they should have dodged. My work on this game focused on three things:

  • Fixing lag: finding what made the game stutter and fixing it so gameplay stays smooth.
  • Smoother animations: improving character and gameplay animations so movement feels fluid and responsive.
  • 3D models: working side by side with the 3D modeler to change existing models and create new ones for the game.

Match & Merge: TMKOC Puzzle

In a merge puzzle, every tile movement is an animation, and players make hundreds of moves in a session. I improved the animations and optimized the game so merges feel snappy and satisfying, even on lower-end devices.

Hungry Goli

Hungry Goli was close to release when I joined the work. I gave it its final polish and performance optimization so it could ship in good shape.

What I learned

  • Optimization is never one big fix. It's many small ones, checked on real devices.
  • Animation quality and performance go together: smooth animation needs a steady frame rate.
  • Working closely with artists early saves a lot of time later, because models built with the game's limits in mind need less rework.

Tech stack

Unity 3D, C#, Unity animation tools, mobile performance tuning, collaboration with 3D artists.
