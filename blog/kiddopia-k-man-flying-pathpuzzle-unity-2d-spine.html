Building Kids Games for Kiddopia: K-Man Flying, PathPuzzle and More (Unity 2D + Spine)

How I built K-Man Flying from scratch with Spine animations, added PathPuzzle to Kiddopia's Puzzles section, and created learning games for toddlers in Unity 2D.

By Sachin Korde, Unity Developer, Pune 2 min read 15 Nov 2026
Unity 2DC#SpineAnimationKids Games

Kiddopia is a popular e-learning app for toddlers, full of small games that teach early skills through play. For a year I developed Unity 2D games for it. Making games for very young children is its own craft: no reading, tiny fingers and short attention spans, so everything has to be obvious, rewarding and fun.

K-Man Flying: an endless space game, built from scratch

K-Man Flying is an endless space-flying game that I built from scratch. The player guides K-Man through space in a game that keeps going as long as they can play.

  • Gameplay from zero: I designed and coded the endless flying loop, controls and game flow.
  • Spine animations: I created the character animations in Spine, a 2D skeletal animation tool. That gave K-Man smooth, lively movement that would be hard to get from frame-by-frame sprites.
  • Responsive controls tuned for toddlers, so the game feels good even with imprecise taps.

PathPuzzle: a new game for the Puzzles section

Kiddopia has a Puzzles section, and I added a new game to it: PathPuzzle. Kids replicate a path to build strategic thinking and problem-solving skills, with animated hints that guide them when they get stuck.

More learning games

I also built ABCD Tracing (letter tracing for early literacy), a Paint game for creative play, Cooking Master, Balloon Pop and Find Correct Word, a game that builds children's vocabulary.

Why Spine?

Spine animates a character as a skeleton with bones instead of drawing every frame. That makes animations smoother, much lighter in memory than big sprite sheets, and easy to tweak. For a kids app with lots of characters and games, those are big wins.

Tech stack

Unity 2D, C#, Spine 2D skeletal animation, mobile touch input.
