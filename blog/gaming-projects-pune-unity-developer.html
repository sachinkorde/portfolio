Gaming Projects by a Pune Game Developer: Unity Mobile, Kids, AR/VR and Multiplayer Games

A complete list of gaming projects I've worked on as a Unity game developer in Pune: TMKOC games, Kiddopia, LiveOps events, AR/VR apps, multiplayer card games and real-time 3D simulations.

By Sachin Korde, Unity Developer, Pune 2 min read 15 Nov 2026
PuneGaming ProjectsUnityPortfolio

Here's every gaming project I've worked on as a Unity game developer from Pune, grouped by type. Each one links to a detailed case study where I explain what I built and what I learned.

Mobile games for TMKOC (India's No. 1 TV serial)

  • TMKOC Playschool Kids Learning: built from scratch, with registration, dashboard, REST APIs, Addressables, localization and learning mini-games. Case study
  • Run Jetha Run: an endless runner I optimized, with smoother animations and new 3D models. Case study
  • Match & Merge: TMKOC Puzzle: animation improvements and optimization.
  • Hungry Goli: final polish and optimization before release.

Kids learning games for Kiddopia

  • K-Man Flying: an endless space-flying game built from scratch, with Spine animations. Case study
  • PathPuzzle: a new game for Kiddopia's Puzzles section.
  • ABCD Tracing, Paint, Cooking Master, Balloon Pop and Find Correct Word: learning games for toddlers.

Live games and LiveOps events

  • Cooking Super Star – Tasty City and World Of Carrom: 3D Board Game: a Diwali festival event, new levels and animated popups. Case study

Card, casino and real-time games

  • Multiplayer Rummy and card games for clients, built with sockets and server-synced game state. Case study
  • Casino Game Suite: Roulette Fun, Roulette 100, Lucky7 Dice Roll, Sic Bo Dice Roll and Fun Target in one app.
  • The Real Bingo: a live number game with 60-second server-synced rounds.

AR, VR and real-time 3D

  • Magic Joey: AR learning cards for kids, built with Augment Works in Pune. Case study
  • Human Anatomy AR and an industrial VR project.
  • Cadaviz: a new section for a virtual human dissection table. Case study
  • Digital Pressure Testing (DPT): 3D drilling-equipment replicas tested with real-time data. Case study
